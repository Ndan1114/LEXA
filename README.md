# 📱 Project UAS Flutter

## Legal & Policy Exploration with Explainable AI (LEXA)

---

## 📌 Deskripsi Aplikasi

**Legal & Policy Exploration with Explainable AI (LEXA)** merupakan aplikasi mobile berbasis Flutter yang dirancang untuk membantu pengguna dalam mengeksplorasi informasi hukum dan kebijakan secara lebih mudah, terstruktur, dan informatif. Aplikasi ini memanfaatkan konsep *Explainable AI* untuk menyajikan data dan hasil analisis dengan penjelasan yang dapat dipahami oleh pengguna, sehingga tidak hanya menampilkan hasil, tetapi juga memberikan konteks dari informasi yang disajikan.

Aplikasi ini dikembangkan sebagai bagian dari **Ujian Akhir Semester (UAS)** mata kuliah *Pemrograman Berbasis Platform 2*.

---

## 🧩 Arsitektur Aplikasi

Aplikasi ini menggunakan arsitektur client-server dengan pembagian sebagai berikut:

* **Frontend**: Dibangun menggunakan Flutter (mobile application)
* **Backend**: REST API (dikembangkan dan dikelola melalui CodePasses)
* **Database**: Menggunakan Railway (struktur database telah disertakan dalam repository)
